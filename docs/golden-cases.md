## 出力項目

「全項目」のケースは、手法（ヒストリカル・ブートストラップ・パラメトリック）ごとに次を出す。ヒストリカルは N ≤ 0 のとき `null`。

- 成功率と成功数
- パーセンタイル: 10 / 25 / 50 / 75 / 90、年 0〜T（NumPy の既定 = 線形補間。破産パスは 0）
- サンプルパス: 本数（ヒストリカルは全パス、それ以外は先頭から最大 200 本）と、先頭と最後のサンプルパスの全年の残高（年 0〜T、破産後は 0）
- 破産年ヒストグラム: 年 1〜T の破産数 `counts` と、別枠の `endedAtZero`（T 年目に倍率 0 で全損したパス。ADR-0003 決定 3）

ケース全体では次を出す。

- N（= 共通期間の年数 − T + 1）と注意段階（`none` / `caution` / `strong` / `noHistory`）
- 逆算（代表手法 = ブートストラップ）: `spending`・`successRate`・`upper`・`capped`・`evaluations`。解がなければ `null`（ADR-0003 決定 1・2）

「成功率のみ」のケースは、N・注意段階と 3 手法の成功率・成功数だけを出す。

### D1 の合成系列

初期資産 1,000、生活費 0、信託報酬 0、T = 3。系列（10 年、添字 0〜9）:

```
[0.05, 0.03, 0.04, 0.02, -1.0, 0.06, 0.01, 0.05, 0.04, -1.0]
```

−100%（倍率 0）を添字 4 と 9 に置く。ヒストリカルは開始年 0〜7 の 8 通り（N = 8、強い注意）で、次の両方が出る。

| 開始年 | 窓 | 結果 |
|---|---|---|
| 2 | 2, 3, **4** | 3 年目（T 年目）に全損 → `endedAtZero` |
| 3 | 3, **4**, 5 | 2 年目に全損 → 3 年目に破産（生活費 0 でも、取り崩し後の残高 0 は破産。spec 7章 決定済み 12） |
| 4 | **4**, 5, 6 | 1 年目に全損 → 2 年目に破産 |
| 7 | 7, 8, **9** | 3 年目に全損 → `endedAtZero` |
| 0, 1, 5, 6 | −100% を含まない | 成功 |

ヒストリカルの成功率は 4 / 8 = 50%。ブートストラップは、1 ブロック（3 年）の開始位置 10 通りのうち 6 通り（2, 3, 4, 7, 8, 9）が −100% を含むため、成功率は 40% 前後になり、生活費 0 でも 90% に届かないので逆算は `null` になる。

パラメトリックは計算しない（`ln(1 + r)` が −∞ になるため）。出力では `parametric: null` とし、理由を `note` に書く。

## 許容誤差（各ケースの JSON に書く）

数値の相対比較は `|a − b| ≤ rel · max(|a|, |b|)` とする（両方 0 なら一致）。

| 対象 | ヒストリカル | ブートストラップ | パラメトリック |
|---|---|---|---|
| 成功率 | 厳密一致 | ±0.5 ポイント | ±0.5 ポイント |
| パーセンタイル・サンプルパスの残高 | 厳密一致 | 相対 1e-9 | 相対 1e-6 |
| 成功数・破産年ヒストグラム・サンプルパス本数 | 厳密一致 | 成功率の許容誤差に従う | 成功率の許容誤差に従う |

- パス数 1,000 でも、成功率の許容誤差は ±0.5 ポイントとする（2026-09-29, 人間の決定。spec 6.2 の「10,000 パス以上」を補う）。
- 逆算: `spending`・`upper` は相対 1e-9、`evaluations` は厳密一致、`capped` と `null` かどうかは厳密一致、`successRate` は ±0.5 ポイント。
- N・注意段階は厳密一致。

## 未確認事項（spec への追記候補）

1. **パラメトリックで `r_real ≤ −1` を含む系列の扱い**。spec 7章 決定済み 5 は `ln(1 + r_real)` の平均と標準偏差を使うとだけ定めており、`1 + r_real ≤ 0` の年を含む系列の扱いは spec に定めがない（2026-09-29 に確認）。
   実データの実質リターンの最小値は −0.565（JPY_WORLD_DM）で、現在の配信データでは起きない。
   追記候補: 「パラメトリックは、`1 + r_real ≤ 0` の年を含む系列を入力検証で拒否する」。spec への反映までは実装しない（ゴールデンでは D1 でパラメトリックを計算しないことで回避する）。
