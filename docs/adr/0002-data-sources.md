# ADR-0002: データソースの選定とライセンス方針

- 状態: **採用**
- 日付: 2026-09-29

## 背景

- 公開アプリのため、再配布可能なデータだけを配信する必要がある（`CLAUDE.md`）。
- 開発環境から外部サイトへの接続に制限があり、実ファイルでの検証は利用者のPCで行う。

## 決定

1. 配信物は**年次の加工値のみ**（`data/processed/returns.json`）。生データは配信しない。
2. ライセンス状態を `cleared / needs-review / blocked` でコード上に持つ（`pipeline/src/fire_data/config.py`）。
   既定のビルドは `cleared` のみ使用。デプロイ前は `validate --strict` が `cleared` 以外の混入を拒否する。
3. 実質化と円建て化は、名目USDリターン・為替変化率・日米インフレを**別々に保存**し、実行時に合成する。
4. 出典は次のとおり。

   | 用途 | 出典 | 状態 |
   |---|---|---|
   | 米国株式（S&P500・配当込み）、金 | Aswath Damodaran（NYU Stern）の年次リターン表 | cleared |
   | 米国CPI | FRED CPIAUCNS（米国労働統計局、public domain・出所明記） | cleared |
   | 為替 | FRED DEXJPUS（Public Domain: Citation Requested） | cleared |
   | 先進国株式（`WORLD_DM`） | Jordà-Schularick-Taylor Macrohistory Database R6（CC BY-NC-SA 4.0） | cleared |
   | 日本CPI | 総務省統計局 消費者物価指数（出所明記＋開発者が加工した旨） | cleared |

5. Damodaran については、人間の判断（2026-09-29）により「データはすべて本人が独自に加工したものであり、使用に問題なし」とする。
6. 金は**1972年以降のみ**使用する（1971年8月の金兌換停止までは公定価格のため）。
7. 出所・加工表記は `returns.json` の `attribution` に含め、画面に常時表示する。`validate` が表記漏れと加工表記の欠落を検出する。
8. 資産の期間が短い場合（金は1972年〜）に備え、標本不足の注意表示と 3 手法の併記を必須にする（`spec.md` 4章 項目9）。
9. `WORLD_DM` は JST の先進18か国の株式総合リターンを USD 換算し等ウェイト合成（1950〜2020年、有効国10か国以上の年のみ）。時価総額加重ではない。UI・文書で「オルカン/ACWI」と呼ばない。
10. JST は CC BY-NC-SA 4.0。人間の判断（2026-09-29）で、非営利の無料Webアプリとして公開し、加工後データも同条件で提供する。広告・課金を入れない。表記は `attribution.notice_ja` に含め、`validate` がライセンス名・非営利・等ウェイトの記載を検査する。
11. Damodaran のインフレ列を FRED CPI 由来のインフレと突き合わせ、**年のずれを `validate` が検出**する（実ファイルの列・行の解釈ミスを検出するため）。

## 結果・トレードオフ

- 利点: ライセンス状態と出所表記の漏れが、コードとゲートで機械的に検出される。
- 欠点: 米国株式（S&P500）は1928年〜（約98年）で、それ以前の長期データはない。
- 欠点: 先進国株式はデータベースの最終年（2020年）までで、以降のリターンは含まれない。
- 欠点: 金は1972年〜（約54年）のため、30年期間のヒストリカルは 25 通り程度。

## 実ファイルでの未検証事項

- `JSTdatasetR6.xlsx` は実ファイルで確認済み（2026-09-29）: 列 `year` / `country` / `eq_tr`（小数）/ `xrusd`（現地通貨/USD）、18か国、1870〜2020年。`eq_tr` には戦間期ドイツ（1921〜23年）に極端な外れ値があるが、1950年より前は使わないため影響しない。
- `histretSP.xls` は「Returns by year」シートの名目リターンのブロック（見出し行の最も左の `Gold` 列まで）から読む。右側の累積値・実質値・リスクプレミアムのブロックは読まない（2026-09-29 に実ファイルの構造で確認・修正済み）。
